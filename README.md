# ひといき — タイマー

HTML・CSS・JavaScriptで作成した日本語のタイマーアプリです。

## 使い方

`index.html` をブラウザーで開いてください。ビルドやパッケージのインストールは不要です。

1. 5分・15分・25分のプリセット、または分・秒の入力で時間を設定します。
2. 「スタート」で計測を開始します。
3. 一時停止・再開・リセットができます。終了音は切り替え可能です。

ブラウザーや端末が休止すると、終了のお知らせが遅れる場合があります。

## ファイル構成

- `index.html`: アプリ画面
- `style.css`: デザインとスマートフォン対応
- `script.js`: タイマー処理と終了音
- `images/timer-icon.jpg`: 表示用の軽量アイコン
- `images/kkrn_icon_tokei_1.png`: 提供されたアイコンの元画像

フォントにはGoogle FontsのNoto Sans JPを使用しています。接続できない場合は端末の標準フォントで表示します。

## 動作確認

JavaScriptの構文チェック:

```sh
node --check script.js
```

ブラウザーでは時間設定、開始、一時停止、再開、リセット、終了表示、終了音を確認できます。
